¿Cómo construir este Dashboard en Excel?

Guía estructurada paso a paso para estudiantes y docentes.

1 Estructura limpia del Libro de Excel (3 Hojas)

Para construir dashboards profesionales, nunca mezcles datos, cálculos e informes. Utiliza 3 pestañas:

  • 1. Datos: Donde va la tabla histórica limpia que cargaste (con columnas Mes, Ingresos, etc.).
  • 2. Cálculos: Espazo privado de soporte para aloxar as túas tablas dinámicas ou fórmulas auxiliares.
  • 3. Dashboard: La hoja de presentación visual (con gráficos, KPIs y segmentadores).

2 Fórmulas para los KPIs principales

En la hoja Cálculos o directamente en tus tarjetas de KPI usando referencias:

Ingresos Totales: =SUMA(Datos!B:B)

Promedio mensual: =PROMEDIO(Datos!B:B)

Porcentaje de Ahorro: =C3 / B3 (Ahorro / Ingresos) - Formato Porcentaje

3 Tablas Dinámicas de Soporte

Na pestana Cálculos, insire dúas tablas dinámicas desde a túa táboa de Datos:

  1. Para el Resumen Anual: Coloca "Mes" agrupado por Años en las Filas, y arrastra "Ingresos", "Ahorro" y el total de categorías a los Valores.
  2. Para la composición del gasto: Coloca los conceptos de gasto en las filas y suma sus montos totales. Ordénala de mayor a menor para obtener el Top.

4 Insertar Gráficos Recomendados e Interactividad

Xera os gráficos a partir das tablas dinámicas:

  • Gráfico de Líneas (Tendencia): Selecciona la tabla de tendencia anual/mensual y agrega un gráfico de líneas para Ingreso vs. Ahorro.
  • Gráfico de Columnas Apiladas: Úsalo para las categorías de gastos. En Excel, haz clic en "Cambiar tipo de gráfico" > Columna Apilada 100% para observar variaciones relativas.
  • Engadir interactividade (Segmentadores): Selecciona calquera gráfico dinámico > Menú Analizar tabla dinámica > Insertar segmentación de datos > Selecciona "Año" y "Mes".
  • Conexión de filtros: Clic dereito sobre o segmentador > Conexións de informes > Marca todas as tablas dinámicas correspondentes para que se actualicen ao mesmo tempo.

5 Estética Profesional

  • Oculta las líneas de cuadrícula: Vista > Mostrar > Desmarcar Líneas de cuadrícula.
  • Usa una única tipografía limpia en todo el archivo (ej. Segoe UI o Aptos).
  • Elige colores unificados: Verde para flujos positivos (ingresos), Rojo/Naranja para gastos y Azul para el ahorro constante.
